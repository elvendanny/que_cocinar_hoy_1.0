# Referencias técnicas

- Spring Boot 3.5, requisitos y documentación: https://docs.spring.io/spring-boot/3.5/system-requirements.html
- Spring Security, JWT: https://docs.spring.io/spring-security/reference/servlet/oauth2/resource-server/jwt.html
- Spring Data JPA: https://docs.spring.io/spring-data/jpa/reference/
- Gmail API, envío: https://developers.google.com/workspace/gmail/api/guides/sending
- OAuth para aplicaciones instaladas: https://developers.google.com/identity/protocols/oauth2/native-app

Versiones concretas de las dependencias gestionadas por Spring Boot 3.5.11 en pom.xml. Proyecto compilado con Java 17; compatible con el JDK 21 usado para la entrega anterior. No se cambia la instalación Java del usuario.
